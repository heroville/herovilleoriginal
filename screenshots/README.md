# Visual baseline screenshots

Screenshots are generated by the visual-capture e2e spec and used to spot UI regressions.

## Usage

1. **Before UI changes:** Run `npm run test:visual`. Screenshots are written here (e.g. `01-fresh-load.png`, `02-after-gather.png`, …).
2. **Make your UI changes.**
3. **After UI changes:** Run `npm run test:visual` again.
4. **Compare:** Use a diff tool on this folder (e.g. `git diff screenshots/`, or an image diff tool) to see what changed.
